# sir

sir is a typed SSA IR. A function is a list of blocks; each block has params,
instructions, and one terminator.

```
function %f(i64, i64) -> i64 {
block0(v0: i64, v1: i64):
    v2 = icmp slt v0, v1
    v3 = select v2, v0, v1
    return v3
}
```

## Types and instructions

Types are `i8`, `i16`, `i32`, `i64`, `f32` and `f64`. Integer ops reject float
operands and float ops reject integers. Instructions:

- `iconst <ty> <n>`: the value is truncated to `<ty>`.
- Unary `ineg`, `bnot`. Binary `iadd`, `isub`, `imul`, `band`, `bor`, `bxor`,
  `ishl`, `ushr`, `sshr`, `sdiv`, `udiv`, `srem`, `urem`. Operands share one
  type and so does the result.
- `icmp <cc> a, b` yields an `i8` that is exactly 0 or 1.
- `select cond, a, b`: `cond` is an `i8`, the arms share a type.
- `sextend <ty> v`, `uextend <ty> v` widen. `ireduce <ty> v` narrows.
- `call fnN(args)`: `fnN` is declared at the top of the function with
  `fnN = %name(types) -> type`. The call yields a value (`v1 = call fn0(v0)`)
  only when the callee returns one. Callees return at most one value.
- `fconst <ty> 0x<bits>` gives the IEEE bit pattern in hex, so NaN payloads
  and infinities are exact (the builder takes an `f64`). `fadd`, `fsub`, `fmul`,
  `fdiv` take two floats of one type.
- `fcmp <cc> a, b` with `eq ne lt le gt ge` yields an `i8` that is 0 or 1. Every
  condition but `ne` is false when an operand is NaN; `ne` is true.
- `fcvt_from_sint <fty> v` and `fcvt_to_sint <ity> v` convert between signed
  ints and floats. A NaN or out-of-range float gives an unspecified int and
  never traps. `fpromote f64 v`, `fdemote f32 v` change width. `bitcast <ty> v`
  reinterprets a float as the int of the same width or back. There are no
  unsigned conversions, `fneg`, `fabs` or `fsqrt`.
- `load <ty> addr` reads memory; `store v, addr` writes it and yields nothing.
  Addresses are plain `i64` values: there is no pointer type, and the 64-bit
  width is fixed on every target.
- `stack_addr ssN` is the address of a stack slot declared at the top of the
  function with `ssN = stack_slot <bytes>`. Slots are 8-byte aligned and live
  until the function returns.

Terminators are `return`, `jump`, `brif`, `switch`, `trap` and `unreachable`.
`brif` needs an `i8` condition. `switch v, k: target, ..., default: target`
tests an integer against each key in order; keys are truncated to the value's
type, and two keys that truncate to the same bits are rejected. Every edge may
pass block args. `trap` traps when executed. `unreachable` marks code that
control never reaches; reaching it is undefined, and both backends trap.
Function params cannot be `i8`.

## Modules

A `Module` holds defined functions and `import %name(types) -> type`
declarations in one namespace. A call names its callee, so a function verifies
on its own (`verify`) and `verify_module` checks that every callee resolves to a
function or import with the same signature. `parse_module` reads the text form.

## Integer widths

Shift amounts are taken modulo the operand's width. Division by zero traps. For
`i64`, `sdiv`/`srem` of the minimum value by -1 also traps. For `i8`, `i16` and
`i32` that case wraps instead.

Backends keep `i8`/`i16`/`i32` in a wider register with undefined upper bits.
Any op that can observe those bits (compares, divides, right shifts, extends)
must extend first. `add`, `sub`, `mul`, bitwise ops, `shl`, `neg` and `not`
don't need to.

## Lessons

- A condition that did not come from `icmp` can have garbage above bit 7. Both
  backends mask it before `brif` and `select`. Skip the mask only when the value
  is defined by an `icmp` instruction. A block param is never safe to skip.
- The parser numbers values by creation order in two passes, so a use can name a
  value defined later. `Function::push_inst` therefore cannot assume operand
  types exist; the verifier reports the bad program.
- A new instruction touches many files. Use the LSP to find every `InstData`
  match instead of grepping.
- Printer output is the filetest format. Changing the syntax means rewriting
  `tests/` text and regenerating autogenerated checks.
